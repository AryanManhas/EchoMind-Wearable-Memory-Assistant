## 🔧 Technical Details

### Memory Structure (Extracted at Stage 4)
```python
{
    "text": str,              # Original/transcribed text
    "type": str,              # meeting|call|reminder|general
    "person": str,            # Named entity
    "time": str,              # Parsed time expression
    "due_time": str,          # ISO 8601 timestamp
    "is_reminder": bool,      # Auto-detected
    "priority": str,          # high|medium|low
    "status": str,            # pending|captured|completed
    "importance_score": float # 0.0-1.0
}
```

### Memory Extraction Examples

**Input:** "Meet John tomorrow at 2 PM"  
**Extracted:**

- person: `John`
- time: `tomorrow at 2 PM`
- priority: `medium`
- is_reminder: `true`

**Input:** "Call Sarah on Friday morning"

- time: `Friday morning`
- priority: `low`
- is_reminder: `false`

**Input:** "Remember to submit report by Monday"  
**Extracted:**
- type: `reminder`
- person: `null`
- time: `Monday`
